# チャット機能 仕様書

## 概要

YmetaLife のチャット機能は、同じルームに参加しているプレイヤー間でテキストメッセージを送受信するリアルタイム通信機能です。
通常チャット（同ルーム全体へのブロードキャスト）と DM（ダイレクトメッセージ、個人宛）の 2 種類をサポートします。

## メッセージ種別

| 種別         | Socket イベント名 | 配信範囲                  |
| ------------ | ----------------- | ------------------------- |
| 通常チャット | `chat_message`    | 同ルームの全プレイヤー    |
| DM           | `dm_message`      | 送信者 + 指定した宛先のみ |

## 機能仕様

### 1. 通常チャット

1. ユーザーがメッセージを入力して送信（フォーム submit または Enter キー）。
2. テキストに `@名前` が含まれない場合、`sendChat(text)` を呼び出す。
3. `Socket.emit("chat_message", { text })` としてサーバーへ送信。
4. サーバーが同ルーム内の全クライアントへ `chat_message` イベントで配信。
5. 受信したクライアントは `appendChatMessage()` で表示を更新。

**サーバー側処理（`server/index.js`）**

- テキストを 200 文字以内にサニタイズ（`String(text).trim().slice(0, 200)`）。
- 空文字や未参加プレイヤーからの送信は無視。
- 配信ペイロード: `{ id: socket.id, name: player.name, text: sanitized }`

### 2. DM（ダイレクトメッセージ）

1. テキストに `@名前` が含まれる場合、`@名前` をすべて解析してメンション先の Socket ID を収集。
2. 各宛先に対して `sendDirectMessage(toId, text)` を呼び出す（複数人への同時 DM も可能）。
3. `Socket.emit("dm_message", { toId, text })` としてサーバーへ送信。
4. サーバーが宛先クライアントのみへ `dm_message` イベントで配信。送信者の表示はクライアント側で直接 `appendDmMessage()` を呼んで行う。
5. 受信したクライアントは `appendDmMessage()` で `fromName(DM)` 形式で表示。

**サーバー側処理（`server/index.js`）**

- 宛先がいずれかのルームに存在するか確認。存在しない場合は無視。
- **レートリミット**: 5 秒間に 10 件まで。超過した場合は送信を無視。
- テキストを 200 文字以内にサニタイズ。
- 配信ペイロード: `{ fromId, fromName, fromRoomId, toId, text }`

### 3. @メンション サジェスト

1. 入力欄で `@` に続いて文字を入力すると、カーソル直前の `@word` を検出。
2. オンラインプレイヤー名（小文字で前方一致）を絞り込んでサジェストリストを表示。
3. キーボード操作:
   - `↑` / `↓`: 候補を上下に移動
   - `Enter` / `Tab`: 選択した候補を入力欄に補完（`@名前 ` の形式で挿入）
   - `Esc`: サジェストを閉じる
4. マウスクリックでも候補を選択可能（`mousedown` で blur を防止）。
5. 入力欄からフォーカスが外れると 150ms 後にサジェストを非表示。

### 4. URL 自動リンク化

- メッセージ本文中の `http://` または `https://` で始まる URL を自動的に `<a>` タグに変換。
- リンクは `target="_blank" rel="noopener noreferrer"` 付きで外部タブに開く。

### 5. パネルの開閉

| 操作                                      | 動作                                 |
| ----------------------------------------- | ------------------------------------ |
| フッターの `💬 チャット` ボタンをクリック | パネルの表示/非表示をトグル          |
| パネルヘッダーの `✕` ボタンをクリック     | パネルを非表示                       |
| 参加（名前フォーム送信）時                | パネルを表示、メッセージ履歴をクリア |

### 6. 入力モードのキャンセル

チャット入力欄（`#chat-input`）にフォーカスが当たっている状態で、マップ（`#game-root`）を `pointerdown` すると入力欄からフォーカスが外れ、入力モードがキャンセルされる。

- キャンバス上でのプレイヤー操作（移動など）が即座に有効になる。
- フォーカスが外れることで @メンション サジェストも 150ms 後に自動的に非表示になる。

## 型定義

```typescript
// src/game/network/types.ts

type ChatMessage = {
  id: string; // 送信者の Socket ID
  name: string; // 送信者のプレイヤー名
  text: string; // メッセージ本文
};

type DirectMessage = {
  fromId: string; // 送信者の Socket ID
  fromName: string; // 送信者のプレイヤー名
  fromRoomId: string; // 送信者のルーム ID
  toId: string; // 宛先の Socket ID
  text: string; // メッセージ本文
};
```

## データフロー図

```
[フロントエンド]                         [サーバー]

chatForm submit
  │
  ├─ @メンションあり
  │    └─ sendDirectMessage(toId, text)
  │         └─ Socket.emit("dm_message")  ──→  レートリミット確認
  │                                             宛先の存在確認
  │                                             サニタイズ
  │                                        ←── Socket.to(toId).emit("dm_message")
  │         appendDmMessage()  ←───────────────┘
  │         ※ 送信者はサーバーエコーなし、クライアント側で直接表示
  │
  └─ @メンションなし
       └─ sendChat(text)
            └─ Socket.emit("chat_message") ──→  サニタイズ
                                           ←── io.in(roomId).emit("chat_message")
            appendChatMessage()  ←──────────────┘
```

## 制約・仕様上の注意点

- **メッセージはルームスコープ**: 通常チャットは同じルームのプレイヤーにのみ届く。ルームを移動すると過去のメッセージは引き続き表示されるが、新着は新しいルームのメンバーに配信される。
- **DM はルームをまたいで送信可能**: 宛先がいずれかのルームに存在すれば届く。全ルームを横断して宛先を検索する。
- **メッセージ履歴は永続化されない**: サーバー再起動やページリロードで過去のメッセージは失われる。
- **プレイヤー名は大文字・小文字を区別しない**: @メンション照合は小文字正規化で行われる。
